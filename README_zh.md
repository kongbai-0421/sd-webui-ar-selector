# 高级分辨率与自定义桶

[English](README.md) | 中文

高级分辨率与自定义桶会在 Forge/WebUI 的生成参数附近添加一个预设分辨率与自定义比例面板。它提供常用 1024、1280 和 1536 基准比例，也支持保存自定义基准与宽高预设。

## 功能

- 提供方形、横向、竖向的预设分辨率按钮。
- 1024 基准预设，适合常规 SDXL/Anima 风格生成。
- 1280 基准预设，适合高清桶分辨率快速设置。
- 1536 基准预设，适合高显存工作流。
- 输入任意 64 的倍数作为基础分辨率，自动生成并保存对应桶分辨率快速栏。
- 自定义基础分辨率标签带有删除叉号，点击后需二次确认。
- 自定义宽高输入并自动计算比例。
- 支持保存、应用、删除自定义预设。
- 自定义预设保存在插件目录下的 `custom_resolutions.json`。
- 自定义基础分辨率保存在插件目录下的 `base_resolution_presets.json`。
- 设置页提供界面语言切换：`zh` 和 `en`。

## 安装

1. 将插件文件夹复制到 WebUI/Forge 的 `extensions` 目录。
2. 重启 WebUI，或使用 Reload UI。
3. 打开 txt2img 或 img2img，面板会显示在宽高参数附近。

## 使用

- 点击预设按钮即可直接设置宽度和高度。
- 在自定义选项卡输入 64 的倍数基础分辨率，可自动计算并添加新的快速设置栏。
- 点击自定义基础分辨率标签右侧的 `×`，并完成两次确认，即可删除该快速设置栏。
- 在自定义选项卡输入任意宽高。
- 保存时可填写名称，也可留空由插件根据比例和尺寸自动生成名称。
- 可选择已保存的自定义预设并应用或删除。

## 预设分组

- **方形**：1:1 尺寸。
- **横向**：4:3、16:9、21:9、全景等宽画幅。
- **竖向**：常见比例的竖版尺寸。

## 语言设置

进入 **设置**，找到 **Advanced Resolution Selector / 高级分辨率选择器**，选择 `zh` 或 `en`，然后 Reload UI。

## 注意

- 插件只写入宽高控件，不修改采样器、模型、提示词或生成逻辑。
- 1536 基准预设会显著增加显存需求。
